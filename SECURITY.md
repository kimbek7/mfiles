# Security policy

## Supported versions

Security fixes go to the latest release.

## Reporting a vulnerability

Please do not open a public issue. Use [private vulnerability reporting](https://github.com/kimbek7/mfiles/security/advisories/new), or write to namusoft7@gmail.com if you cannot. Include the steps to reproduce and the impact.

Issues of particular interest are anything that could overwrite or lose user files, move files outside the chosen folders, or let the interface reach the file system directly.
