# Changelog

All notable changes to this project are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-06

### Added

- Streaming scan with a live treemap, content-based type detection and EXIF dates.
- Grouping by type, year, month and size in any order, with a preview of every path.
- Staged duplicate detection by size and hash.
- Topic folders that move as a whole, with a per-folder decision on the plan screen.
- Moves with a write-ahead journal, verified copies across drives and full undo, also after a crash.
- Change list in CSV next to the sorted files.
- Particle flow scene and a simulation mode that touches no files.
- English and Polish interface.
- Windows installer and portable builds.
